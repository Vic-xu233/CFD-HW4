# 📌 二维稳态热传导模拟（SOR 方法）

本项目基于 Python 实现了**二维稳态热传导方程**的数值解，使用了 **超松弛迭代法（Successive Over-Relaxation, SOR）**，并包含了**自动寻找最优松弛因子 ω** 以及 **网格敏感性分析** 的功能。

## 🔧 核心功能

- 使用 SOR 方法高效求解二维热传导差分方程
- 自动搜索最优松弛因子 ω 以加速收敛
- 支持多种网格划分 (Nx × Ny)，自动遍历并记录最优 ω
- 绘制温度等值线图，展示热传导过程
- 分析“网格数量 vs 最优 ω”的关系趋势图

## 🧠 算法介绍

1. **SOR 迭代：**  
   对二维温度场逐点更新直至收敛，利用控制参数 ω 加速收敛过程。

2. **自动优化 ω：**  
   通过分阶段缩小搜索区间的方式，自动寻找在当前网格下能达到最快收敛速度的 ω。

3. **网格扫描：**  
   对多个不同网格密度的情况，重复运行主程序，收集最优 ω 值并绘图分析其变化规律。

## 📈 输出结果

- 每组网格 `(Nx, Ny)` 下的最优松弛因子 ω 和收敛迭代次数
- 对应的温度分布图（等温线图）
- 横轴为“总网格数 Nx × Ny”，纵轴为“最优 ω”的趋势图
